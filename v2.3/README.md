# Discord 实时翻译助手 v2.3

看 Discord 外文社区时的鼠标悬停翻译工具。鼠标停在消息上，正上方弹出半透明气泡显示译文，移开即消失。

- 直接读 Discord 页面的真实文字（不是 OCR / 截图识别），准确率 100%，无识别延迟
- **普通消息、机器人卡片（Embed / Components V2）、抽奖与投票卡片都能翻译**
- 卡片里会精确翻译鼠标所指的那一段，悬停在卡片留白处则翻译整张卡片
- **目标语言可切换（13 种）**：中文 / English / 日本語 / 한국어 / Русский / Español / Français / Deutsch / Português / Italiano / Tiếng Việt / ไทย / العربية
- **界面语言可切换**：简体中文 / English（给外国同事用）
- **已经是目标语言的内容不会翻译**，也不发请求 —— 又准又快又省钱
- **气泡颜色和透明度可调**（12 个预设色 + 自定义取色器）
- 翻译结果本地缓存，同一句不重复请求、不重复扣费
- 不修改 Discord 任何文件，也不读取账号密码

## 二、快速开始

**1. 申请自己的 DeepSeek API Key**

打开 <https://platform.deepseek.com/> 注册 → 创建 API Key（`sk-` 开头）。
新账号有免费额度，日常浏览聊天记录一个月通常只要几毛钱。

> ⚠️ 不要几个人共用一个 Key：额度会被一个人用光，而且所有人都能看到这个 Key。

**2. 双击 `launcher.exe`**

程序会自动完成：结束当前 Discord → 带调试接口重新启动 → 等待主界面 → 注入翻译功能。

> 启动前请保存好 Discord 里正在输入的内容，因为它会先关闭 Discord。

**3. 首次配置**

右下角出现半透明「译」字圆球后，右键它 → **设置** → 粘贴你的 API Key → 点「测试」确认可用 → 保存。

设置面板里还能改这些（都在同一个面板）：

| 项 | 作用 |
|---|---|
| 界面语言 | 菜单和面板的语言：简体中文 / English |
| 目标语言 | 想翻译成哪种语言（13 种可选） |
| 气泡颜色 | 12 个预设色 + 自定义取色器；文字颜色会自动配（浅底深字、深底浅字） |
| 气泡透明度 | 10% ~ 100% |
| 触发延迟 | 鼠标停多久才翻译，100 ~ 1000ms |

面板底部有**实时预览**，改颜色和透明度能立刻看到效果。

**4. 开始使用**

鼠标悬停在消息上 → 上方弹出译文气泡；鼠标移开 → 气泡消失。

## 二·五、多语言是怎么工作的

设置里的**目标语言**决定翻译方向：

- 鼠标悬停的文本**只要不是目标语言**，就翻译成目标语言
- 悬停的文本**已经是目标语言**，就**不翻译**，也不发请求（所以更快、更省）

举例：

| 目标语言 | 悬停英文 | 悬停中文 | 悬停俄文 |
|---|---|---|---|
| 简体中文 | 翻成中文 | 不翻译 | 翻成中文 |
| Русский | 翻成俄语 | 翻成俄语 | 不翻译 |
| English | 不翻译 | 翻成英语 | 翻成英语 |

判断"是不是目标语言"在本地完成，用两套办法：
1. **字符集判断** —— 中文/日文/韩文/俄文/泰文/阿拉伯文各有专属字符，识别几乎不会错
2. **虚词打分** —— 剩下的拉丁字母文本（英/西/法/德/葡/意/越）按常见虚词投票

识别不出来时（太短、纯数字、纯表情）会交给大模型，模型发现原文已是目标语言会原样返回，页面比对后就不显示气泡 —— 所以**任何情况下都不会弹出"和原文一模一样"的气泡**。

## 四、重要说明

**launcher.exe 必须保持运行。** 它不只是启动器，同时是翻译请求的转发器——关掉它翻译就会停止。
启动后它的窗口会自动隐藏，不用管它。要彻底退出：右键悬浮球 → 退出翻译助手。

**每次都要用 launcher.exe 启动 Discord。** 直接用 Discord 自带的快捷方式启动不会加载翻译功能（因为没有开启调试接口）。

**必须用 launcher.exe 重新启动的原因**：Discord 已经在运行时，它不会接受新的启动参数，所以程序会先关掉它再用新参数拉起。

## 五、常见问题

**Q: 双击 exe 后 Windows 提示"已保护你的电脑"/ 杀毒软件报警？**

这是 PyInstaller 打包程序的常见误报（因为很多恶意软件也用同样的打包方式），不是真的病毒。可以：
1. 点「更多信息」→「仍要运行」
2. 如果被杀毒软件拦截，把 `launcher.exe` 加入白名单

如果公司电脑安全策略很严，建议先让 IT 同事过一眼，或者直接用源码运行 `launcher.py`（需要 Python + `websocket-client`）。

**Q: 右下角没有悬浮球？**

1. 确认是用 `launcher.exe` 启动的
2. 确认代理软件开着（Discord 能正常登录）
3. 看同目录下的 `dt_bridge.log` 日志

**Q: 提示"翻译服务未连接"？**

`launcher.exe` 已经退出了，重新双击它即可。悬浮球右键菜单里能看到「翻译服务已连接 / 未连接」。

**Q: 提示"DeepSeek 账户余额不足"？**

去 <https://platform.deepseek.com/> 充值。

**Q: 有些消息悬停没反应？**

先确认这几类，它们本来就不翻译：
- **已经是目标语言的内容**（比如目标语言是中文，悬停中文消息就不翻）
- 纯表情、纯链接、纯图片/视频消息
- 用户名、时间戳等界面元素

机器人发的**卡片消息（Embed）是支持的**。如果某条卡片还是不翻译，把截图发出来，多半是 Discord 又换了新的 DOM 结构。

**Q: 重启了 launcher.exe，但翻译一直提示"服务响应超时"？**

正常情况下程序启动时会自动清理上一次的残留通道，不用管。如果日志里出现「通道自检未通过」，在 Discord 里按一次 `Ctrl+R` 刷新页面即可。

**Q: 我用的是 Discord 里内嵌的小游戏 / 活动，那里会不会也冒出悬浮球？**

不会。脚本只在外层 Discord 窗口创建界面，内嵌的网页内容（活动、小游戏）里不会出现。

**Q: 会不会影响 Discord 账号 / 会被封号吗？**

程序只在运行时往页面里注入界面元素，不改 Discord 文件、不碰账号登录信息、不自动化任何账号操作，风险很低。但它确实是通过调试接口注入的，严格来说属于非官方增强，是否使用请自行判断。

## 七、技术原理（给好奇的人）

Discord 桌面版是 Electron 应用。这个工具做了三件事：

1. **用调试端口启动 Discord**，通过 Chrome DevTools Protocol 注入脚本，往页面里加悬浮球和气泡
   （试过 Chrome 扩展方案，但 Electron 不执行扩展的 content script，此路不通）

2. **直接读页面的真实文字**，而不是截图 + OCR 识别，所以准确率和速度都远好于 OCR

3. **翻译请求由外部程序（launcher.exe）代发**
   Discord 页面有 CSP `connect-src` 限制，页面里直接请求外部 API 会报 `Failed to fetch`。
   所以页面脚本通过 CDP 的 `Runtime.addBinding` 注册的原生函数，把翻译请求"呼叫"给 launcher.exe，
   由它用 Python 发 HTTPS 请求，再把结果回传页面渲染。

更完整的踩坑记录见 `方案文档.md`。
