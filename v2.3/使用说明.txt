=========================================
   Discord 实时翻译助手 v2.3
=========================================

【快速开始】

1. 保持代理软件（v2rayN 等）开启且正常工作

2. 双击 launcher.exe

3. 程序会自动：
   - 结束当前 Discord
   - 重新启动 Discord（带调试接口）
   - 等待主界面加载
   - 注入翻译功能并建立翻译通道

4. 看到右下角出现半透明"译"字圆球 = 成功
   （启动窗口会自动隐藏，程序在后台继续运行）

5. 首次使用：右键悬浮球 -> 设置 -> 填入 DeepSeek Key -> 点"测试"-> 保存
   API Key 免费获取：https://platform.deepseek.com/ 注册后创建

   同一个设置面板里还能改：
     界面语言   简体中文 / English（外国同事用这个）
     目标语言   想翻译成哪种语言（13 种）
     气泡颜色   12 个预设色 + 自定义取色器
     气泡透明度 10% ~ 100%
     触发延迟   100 ~ 1000ms
   面板底部有实时预览，改颜色和透明度立刻能看到效果

6. 鼠标悬停在消息上 -> 译文气泡显示在原文正上方
   鼠标离开 -> 气泡立刻消失


【重要说明】

* launcher.exe 启动后必须保持运行（窗口会自动隐藏，不用管它）
  它同时是"翻译请求的转发器"，关掉它翻译就会停止
  要彻底退出：右键悬浮球 -> 退出翻译助手

* 每次都要用 launcher.exe 启动 Discord
  直接用 Discord 自带快捷方式启动不会加载翻译功能

* launcher.exe 会先关闭正在运行的 Discord 再重启
  启动前请保存好正在输入的内容

* 必须开着代理软件（Discord 本身在国内需要代理才能使用）


【悬浮球操作】

- 左键单击：开启/关闭翻译（绿边=开，红边=关）
- 右键单击：功能菜单（设置 / 清缓存 / 收起 / 退出）
- 拖拽：移动到任意位置（自动记忆）
- 双击：收起为小点（再双击展开）
- 10秒不操作：自动变暗到 15%（不干扰观看）
- 鼠标放上去：恢复正常显示


【翻译功能】

- 鼠标悬停消息 -> 自动翻译（防抖延迟默认 300ms，可调）
- 翻译结果以半透明气泡显示在消息正上方
- 气泡不遮挡内容（鼠标可穿透），离开立刻消失
- 相同句子自动缓存，不重复请求 API、不重复扣费
- 气泡颜色、透明度可调（设置面板，带实时预览）

支持的翻译对象：
- 普通文字消息
- 机器人卡片消息（Embed / 新版 Components V2 卡片，如抽奖、投票、公告）
  悬停在卡片里某一段文字 -> 只翻译那一段
  悬停在卡片留白处 -> 翻译整张卡片

翻译方向（由"目标语言"决定）：
- 悬停的文本只要不是目标语言，就翻译成目标语言
- 悬停的文本已经是目标语言，就不翻译、也不发请求（更快更省钱）

  目标语言=简体中文：英文消息->翻成中文   中文消息->不翻   俄文消息->翻成中文
  目标语言=Русский  ：英文消息->翻成俄语   中文消息->翻成俄语  俄文消息->不翻
  目标语言=English  ：英文消息->不翻       中文消息->翻成英语  俄文消息->翻成英语

  可选：简体中文 / English / 日本語 / 한국어 / Русский / Español / Français /
        Deutsch / Português / Italiano / Tiếng Việt / ไทย / العربية

不翻译的内容（设计如此）：
- 已经是目标语言的内容
- 纯表情、纯链接、纯图片/视频消息
- 用户名、时间戳等界面元素


【配置文件】

dt_config.json（和 launcher.exe 同目录）保存了所有设置：

  apiKey      DeepSeek API Key
  enabled     1=翻译开启 0=翻译关闭
  uiLang      界面语言：zh=简体中文 en=English
  targetLang  目标语言：zh / en / ja / ko / ru / es / fr / de / pt / it / vi / th / ar
  bubbleBg    气泡背景色（#RRGGBB）
  opacity     气泡透明度 0.1~1
  debounce    触发延迟（毫秒）
  model       使用的模型（默认 deepseek-chat）
  ballX/Y     悬浮球位置

可以直接用记事本编辑（改完重启程序生效），
也可以在悬浮球右键菜单里改（即时生效）。

注意：dt_config.json 里保存了你的 API Key，
      分享给他人前请把 apiKey 字段清空。


【常见问题】

Q: 右下角没有悬浮球？
A: 1) 确认是用 launcher.exe 启动的
   2) 确认代理软件已开启（Discord 能正常登录）
   3) 看同目录下 dt_bridge.log 里的日志

Q: 翻译没反应 / 显示"翻译服务未连接"？
A: launcher.exe 已退出。重新双击 launcher.exe 即可
   （悬浮球右键菜单会显示"翻译服务已连接/未连接"）

Q: 重启 launcher.exe 后一直提示"翻译服务响应超时"？
A: 程序启动时会自动清理上一次的残留通道，一般不会出现。
   万一出现，日志里会写"通道自检未通过"，
   在 Discord 里按一次 Ctrl+R 刷新页面即可。

Q: 悬停消息没有任何反应？
A: 先确认不是这几种情况：
   - 内容已经是"目标语言"了（比如目标语言是中文，悬停中文消息本来就不翻）
   - 纯表情 / 纯链接 / 纯图片视频
   如果是机器人卡片还不翻，把截图发出来

Q: 在 Discord 里玩内嵌的小游戏/活动，会不会也冒出悬浮球？
A: 不会。脚本只在外层 Discord 窗口创建界面，内嵌内容里不会出现。

Q: 提示"DeepSeek 账户余额不足"？
A: 去 https://platform.deepseek.com/ 充值即可，新账号有免费额度

Q: 提示"API Key 无效"？
A: 检查 Key 是否复制完整（以 sk- 开头），或在设置里点"测试"验证

Q: 为什么必须用 launcher.exe？
A: 翻译功能通过调试接口注入到 Discord，需要特定启动参数，
   直接用 Discord 快捷方式启动无法注入

Q: 为什么启动时 Discord 被关闭了？
A: 已运行的 Discord 没有开启调试接口，必须先关闭再用新参数启动

Q: 会不会影响 Discord 本身 / 会被封号吗？
A: 不会修改 Discord 任何文件，只在运行时注入界面元素，
   也不读取你的账号密码。属于本地辅助工具，风险极低

Q: API 收费吗？
A: DeepSeek 价格很低（约 1 元 / 百万字），相同句子有缓存不重复扣费
   日常浏览聊天记录，一个月通常几毛钱

【技术原理】

Discord 桌面版基于 Electron。实测发现：
  (1) Electron 不完整支持 Chrome 扩展，--load-extension 的
      content script 不会执行 —— 所以放弃了扩展方案
  (2) Discord 页面设置了 CSP: connect-src，页面里 fetch 外部 API
      会直接报 "Failed to fetch" —— 所以放弃了页面直连

最终方案：CDP 注入 + 原生桥接

  launcher.exe
      | 带 --remote-debugging-port 启动
  Discord（Electron）
      | CDP 连接，注入 inject.js（悬浮球 + 气泡 + 悬停翻译）
      |
  鼠标悬停 -> 读取 DOM 真实文字（不是 OCR，100% 准确）
      |
  页面 JS 调用原生函数 __dtNative（CDP Runtime.addBinding）
      |
  launcher.exe（Python）代为请求 DeepSeek API  <- 绕开 CSP
      |
  结果回传页面 -> 黑色半透明气泡显示在原文上方

优点：
  · 不依赖扩展机制，不受 Electron 限制
  · 直接读 DOM 文字，100% 准确、零延迟
  · 网络请求在 Python 侧发起，彻底绕开页面 CSP
  · 配置存本地文件，重启不丢失
